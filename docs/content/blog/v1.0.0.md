Rotini v1.0.0 has been released - the first stable release of Rotini for Go!

Rotini is a spec-driven CLI framework: you declare your commands, flags and arguments in a
spec file, Rotini generates the typed Go and a handler stub for each command, and you write
what each command does.

See the [documentation](/docs/) to get started.
