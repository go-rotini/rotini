Rotini v1.0.0 has been released.

Rotini is a spec-driven CLI framework for Go. You declare your commands, flags, and arguments in a
spec file, then rotini generates typed Go and a handler stub for each command; you write
what each command does.

See the [documentation](/docs/) to get started!
