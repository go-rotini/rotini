# Generated Code

rotini generates **what is yours** and imports **what is ours**. Your CLI's shape — its command tree, typed inputs, and help text — is unique to your project, so it is written into your repo where you can read it, diff it, and own it. The machinery is an ordinary versioned import.

`rotini init` generates **342 lines across 5 files** — and they are a CLI that already
answers `--help`, `--version`, `help <command>` and `version`, because the seeded spec
declares them and the seeded handlers are wired to the pages codegen just produced. Nothing
is injected at run time; every line is in your repo, and every line is yours to delete.

## What lands where

The `.rotini.conf.*` file declares two package targets. Everything rotini writes goes to one of them.

| Target | Contents | Overwritten? |
|---|---|---|
| `main` | the binary entrypoint, carrying the `//go:generate` directive | **never** — create-once, because it holds your build metadata |
| `cmd` | the one generated file **plus** one editable handler stub per command | the generated file every pass; stubs **never** after creation |
| `models` | **optional** — the typed structs, split into their own package so a handler package can import them without a cycle (see [configuration](/configuration)) | every pass |

There is no `runtime` target: the rotini runtime is a library you `go get`, not emitted code.

## The generated file

One file per CLI, marked `DO NOT EDIT`, holding four things:

{{< code title="internal/cmd/todo/zz_todo.go" language="golang" open="true" collapsible="false" copy="false" >}}
// Code generated by rotini; DO NOT EDIT.
package todo

import (
	"github.com/go-rotini/rotini"
)

// 1. The aggregate handler interface — the compiler checks you implement every command.
type ProgramHandlers interface {
	Todo() rotini.Handlers
	TodoAdd() rotini.Handlers
}

// 2. The command tree, as data.
var definition = rotini.Definition{
	Name:    "todo",
	Handler: "Todo",
	Commands: []rotini.CommandDef{
		{Name: "add", Handler: "TodoAdd", Summary: "add a task", /* … */},
	},
}

// 3. The typed inputs — what Collect[T] decodes into. You never write these.
type TodoAddFlags struct {
	Due time.Time `rotini:"due"`
}

type TodoAddArguments struct {
	Title string `rotini:"title"`
}

type TodoAddInputs struct {
	Todo    TodoCommandInputs
	TodoAdd TodoAddCommandInputs
}

// 4. The rollup: the wiring, and the ready-to-run Program.
var Program = NewProgram(&handlers{})
{{< /code >}}

`NewProgram` takes the typed `ProgramHandlers`, so **a command without a handler is a compile error**, not a runtime surprise.

## Handler stubs

One per command, created once and then yours. rotini never touches a stub again — regenerate as often as you like.

Stubs and the generated types share **one package**, so a handler refers to its own input type unqualified:

{{< code title="internal/cmd/todo/todo_add.go" language="golang" open="true" collapsible="false" copy="true" >}}
func (*todoAddHandlers) Run(ctx context.Context, rtx *rotini.Context) {
	inputs, err := rotini.Collect[TodoAddInputs](rtx) // not somepkg.TodoAddInputs
	if err != nil {
		rtx.RecordError(err)
		return
	}
	// …
}
{{< /code >}}

## Pruning

Generated files that no longer map to a command are **removed** on each pass, so deleting a command from the spec deletes its generated code. Hand-written files in the same directory are spared — test files and seeded templates automatically, anything else via the conf's `keep` list.

## Derived outputs

Help pages, man pages, markdown reference pages and shell completion scripts are each an opt-in feature in the conf, with two orthogonal knobs:

- **`embed`** — write the rendered content to a file and reference it with `//go:embed`, or (the default) inline it as a string literal so the generated `.go` is self-contained.
- **`template`** — seed an editable `*.tmpl` you can restyle, or (the default) render from rotini's built-in.

Because these are generated at codegen rather than produced by running your binary, they land in your diff and can be reviewed like any other change.
